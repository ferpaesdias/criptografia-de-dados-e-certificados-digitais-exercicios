# Scripts de referência

Versões prontas dos scripts do laboratório, para **conferência**. Durante a aula, digite os scripts seguindo o roteiro: entender cada linha faz parte do exercício.

| Script | Uso |
|---|---|
| `cesar.sh` | `./cesar.sh <deslocamento> "texto"` (deslocamento negativo decifra) |
| `vigenere.sh` | `./vigenere.sh cifrar\|decifrar CHAVE "texto"` |

Para comparar o seu script com a referência:

```bash
diff ~/lab-cifras/cesar.sh cesar.sh
```
