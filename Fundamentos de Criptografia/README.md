# Fundamentos de Criptografia

Conceitos básicos que sustentam toda a criptografia moderna: **algoritmo**, **chave**, **texto claro**, **texto cifrado** e **criptografia simétrica**. As cifras clássicas são usadas aqui como ponto de partida, porque permitem fazer à mão o que os algoritmos modernos fazem em escala, e mostram na prática por que chaves fracas comprometem qualquer sistema.
